## poseidon_attack（t=2)
### 运行
需要运行几轮，可以通过改最后for循环里的参数即可

``for r in range(1, 6):
    attack_rounds(r)``

可以修改代码开头的Ture/False来改变域的大小（True: 256位大域, False: GF(101)小域）
```# ============================================================================
# 域选择 —— 修改此处切换小域/大域
# ============================================================================
USE_LARGE_FIELD = True  # True: 256位大域, False: GF(101)小域
```
